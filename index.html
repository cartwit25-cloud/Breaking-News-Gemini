    開啟 Google Sheet → 擴充功能 → Apps Script

    貼入 apps-script.gs 內容，填入 Anthropic API Key
  3. 3
    部署 → 新增部署 → Web 應用程式
    執行身分：我，存取：所有人

    複製 Web App URL 貼入上方欄位
